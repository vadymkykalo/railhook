Railhook надсилає вебхуки вашого продукту й приймає ті, на які він покладається, повторює невдалі спроби й записує кожну з них.

- [Швидкий старт](/docs/uk/start/quickstart/): від нуля до доставленого вебхука.
- [Власний сервер](/docs/uk/self-hosting/overview/): що запускає інсталяція і що їй потрібно.
- [Довідник API](/docs/uk/api-reference/): усі ендпоінти із запитами, які можна надіслати на ваш інстанс.

Railhook Cloud працює на [railhook.io](https://railhook.io/register), почати можна безкоштовно. Щоб запустити його на власному сервері (близько 4 ГіБ оперативної пам'яті):

```bash title="Встановлення на власний сервер"
curl -fsSL https://railhook.io/install.sh | bash
```
