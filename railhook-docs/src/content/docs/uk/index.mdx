Railhook доставляє вебхуки, які надсилає ваш продукт, і приймає ті, на які він покладається: повторює невдалі спроби й зберігає історію кожної з них. Користуйтеся Railhook Cloud або встановіть його на власний сервер.

<CardGrid>
<Card title="Railhook Cloud — безкоштовна реєстрація">

Railhook працює на railhook.io. Зареєструйтеся й почніть із безкоштовного плану; платні плани з підтримкою та вищими лімітами з'являться згодом.

<LinkButton href="https://railhook.io/register" variant="primary">Зареєструватися безкоштовно</LinkButton>

</Card>
<Card title="Власний сервер — одна команда">

Інсталятор перевіряє сервер, створює Compose-файл і `.env` зі згенерованими секретами, а потім запускає стек. Знадобиться близько 4 ГіБ оперативної пам'яті.

</Card>
</CardGrid>

```bash title="Встановлення на власний сервер"
curl -fsSL https://railhook.io/install.sh | bash
```
