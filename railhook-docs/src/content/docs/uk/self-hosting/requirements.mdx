Перевірте це перед встановленням. Інсталятор перевіряє те саме й не продовжує, доки перевірки не пройдуть. На вже встановленому інстансі ці перевірки повторно запускає `./railhook doctor`.

## Хост

| Ресурс | Вимога |
|---|---|
| Docker | Docker Engine 20.10 або новіший, демон запущений і доступний вашому користувачу |
| Compose | Compose v2, як `docker compose` або окремий `docker-compose` |
| Пам'ять | Близько 4 ГіБ. Від 2 до 4 ГіБ інсталятор попереджає про свопінг, менше ніж 2 ГіБ — зупиняється |
| Диск | Щонайменше 5 ГіБ вільного місця для образів, плюс місце для бази даних і журналу Kafka |
| Інструменти | `curl` і `openssl`: ними інсталятор завантажує файли й генерує секрети |

Стек запускає дві JVM, брокер, базу даних і кеш. Нижче наведено типові ліміти пам'яті контейнерів. Кожен можна змінити в `.env`:

| Сервіс | Ліміт | Змінна |
|---|---|---|
| `api` | 768m | `API_MEMORY_LIMIT` |
| `worker` | 768m | `WORKER_MEMORY_LIMIT` |
| `postgres` | 1G | `POSTGRES_MEMORY_LIMIT` |
| `kafka` | 1G | `KAFKA_MEMORY_LIMIT` |
| `redis` | 512m | `REDIS_MEMORY_LIMIT` |
| `ui` | 128m | `UI_MEMORY_LIMIT` |

## Порти

| Порт | Коли |
|---|---|
| `80` | Без домену. Змініть через `--port`, якщо його вже зайнято |
| `80` і `443` | З `--domain`. Обидва мають бути вільні, бо їх займає TLS-термінатор |

Нічого іншого на хості не публікується.

## Мережа

- **Вхідний трафік:** лише порт вище, звідусіль, де є ваші користувачі та провайдери вебхуків.
- **Вихідний трафік для встановлення й оновлення:** `raw.githubusercontent.com` і `api.github.com` для файлів релізу та `ghcr.io` для образів.
- **Вихідний трафік для доставки:** HTTP і HTTPS до ваших ендпоінтів і призначень, на будь-яких портах, які вони використовують.

<Aside type="caution">
Типово Railhook не доставляє на приватні та внутрішні IP-адреси, щоб через ендпоінт не можна було дістатися вашої внутрішньої мережі. Щоб дозволити один конкретний внутрішній хост, додайте його до `WEBHOOK_ALLOWED_HOSTS`, а не вимикайте захист.
</Aside>

## Kubernetes

Helm-чарт потребує Kubernetes 1.24+ і Helm 3.8+, а також ваших власних PostgreSQL 16+, Kafka 3.7+ і Redis 7+. Див. [Kubernetes](/docs/uk/self-hosting/kubernetes/).
