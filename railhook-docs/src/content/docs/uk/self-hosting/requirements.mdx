Інсталятор зупиняється, якщо немає Docker, Compose, 2 ГіБ пам'яті чи вільного порту, і попереджає, коли пам'яті або диска менше за рекомендоване. На встановленому інстансі `./railhook doctor` перевіряє Docker, Compose і конфігурацію на диску.

## Хост

| Ресурс | Вимога |
|---|---|
| Docker | Docker Engine 20.10 або новіший; демон має бути запущений і доступний вашому користувачу |
| Compose | Compose v2, як `docker compose` або окремий `docker-compose` |
| Пам'ять | Близько 4 ГіБ. Якщо пам'яті від 2 до 4 ГіБ, інсталятор попередить, що системі доведеться використовувати своп; якщо менше ніж 2 ГіБ — зупиниться |
| Диск | Щонайменше 5 ГіБ вільного місця для образів, а також місце для бази даних і журналу Kafka. Якщо менше ніж 5 ГіБ, інсталятор попередить |
| Інструменти | `curl` і `openssl`: ними інсталятор завантажує файли й генерує секрети |

Стек запускає дві JVM, брокер, базу даних і кеш. Типові ліміти пам'яті для кожного контейнера, кожен задається в `.env`:

| Сервіс | Ліміт | Змінна |
|---|---|---|
| `api` | 768m | `API_MEMORY_LIMIT` |
| `worker` | 768m | `WORKER_MEMORY_LIMIT` |
| `postgres` | 1G | `POSTGRES_MEMORY_LIMIT` |
| `kafka` | 1G | `KAFKA_MEMORY_LIMIT` |
| `redis` | 512m | `REDIS_MEMORY_LIMIT` |
| `ui` | 128m | `UI_MEMORY_LIMIT` |

## Порти

| Порт | Коли |
|---|---|
| `80` | Без домену. Якщо порт уже зайнято, змініть його через `--port` |
| `80` і `443` | З `--domain`. Обидва мають бути вільними, бо їх займає TLS-термінатор |
| `8080` на `127.0.0.1` | З `--domain --behind-proxy`. Порти 80 і 443 лишаються за вашим проксі. Змінити порт можна через `--port` |

Нічого іншого на хості не публікується.

## Мережа

- **Вхідний трафік:** єдиний порт, указаний вище, доступний звідусіль, де перебувають ваші користувачі та провайдери вебхуків.
- **Вихідний трафік для встановлення й оновлення:** `raw.githubusercontent.com` і `api.github.com` для файлів релізу та `ghcr.io` для образів.
- **Вихідний трафік для доставки:** HTTP і HTTPS до ваших ендпоінтів і призначень, на будь-яких портах, які вони використовують.

<Aside type="caution">
Типово Railhook відмовляє приватним і внутрішнім IP-адресам, тож ендпоінт не дістанеться вашої внутрішньої мережі. Щоб дозволити один внутрішній хост, додайте його до `WEBHOOK_ALLOWED_HOSTS`, а не вимикайте захист.
</Aside>

## Kubernetes

Helm-чарт потребує Kubernetes 1.24+ і Helm 3.8+, а також PostgreSQL 16+, Kafka 3.7+ і Redis 7+, які ви надаєте самі. Див. [Kubernetes](/docs/uk/self-hosting/kubernetes/).
