Railhook — проєкт із відкритим кодом під ліцензією MIT. На власному сервері вам доступні всі функції: без ліцензійного ключа й заблокованих модулів. Цей розділ пояснює, як запустити Railhook на власній інфраструктурі. Якщо не хочете обслуговувати його самі, [Railhook Cloud](https://railhook.io/register) — той самий продукт, який запускають за вас.

## Що запускається

| Сервіс | Роль |
|---|---|
| `ui` | nginx. Віддає панель керування й проксує шляхи API, ingress і тунелів. Єдиний сервіс, порт якого опубліковано на хості |
| `api` | Приймає події та вхідні вебхуки, обслуговує REST API. Під час запуску виконує міграції бази даних |
| `worker` | Виконує спроби: підписує, надсилає, повторює |
| `postgres` | Основне сховище даних |
| `kafka` | Передає роботу від API до воркера. `kafka-init` створює топіки під час першого запуску |
| `redis` | Ліміти запитів, дозволи на паралельні запити, стан circuit breaker |
| `caddy` | Необов'язковий. Термінує HTTPS, якщо ви встановлюєте Railhook з доменом |
| `db-backup` | Необов'язковий. Робить дамп бази даних за розкладом |

Усе проходить через один порт: панель, API, ingress-адреси та тунель CLI. Postgres, Kafka, Redis і сам API доступні лише всередині мережі Docker. Отже, вам потрібні одна адреса, яку ви всім даєте, один сертифікат і одне правило брандмауера.

## Способи розгортання

| Спосіб | Коли використовувати |
|---|---|
| [Інсталятор](/docs/uk/self-hosting/install-docker/) | Типовий спосіб. Одна команда на Linux-хості з Docker. Інсталятор генерує секрети й лишає по собі звичайне розгортання на Compose |
| [Docker Compose вручну](/docs/uk/self-hosting/install-docker/) | Ви керуєте файлами власними інструментами керування конфігурацією |
| [Kubernetes з Helm](/docs/uk/self-hosting/kubernetes/) | У вас уже є Kubernetes, а PostgreSQL, Kafka й Redis ви надаєте самі |
| [З клону репозиторію](/docs/uk/self-hosting/local-development/) | Ви розробляєте сам Railhook |

<Aside type="tip">
Почніть з інсталятора, навіть якщо згодом плануєте перейти на Kubernetes: змінні конфігурації скрізь однакові.
</Aside>
