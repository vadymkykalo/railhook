SDK покривають ті частини API, які ви викликаєте з коду застосунку: події, ендпоінти, підписки, доставки, вхідні джерела й вхідні події, а також перевірку підпису. Для автентифікації їм достатньо самого API-ключа.

| Мова | Пакет | Встановлення |
|---|---|---|
| Node.js / TypeScript | [`@railhook/node`](https://www.npmjs.com/package/@railhook/node) | `npm install @railhook/node` |
| Python | [`railhook`](https://pypi.org/project/railhook/) | `pip install railhook` |
| PHP 8.1+ | [`railhook/php`](https://packagist.org/packages/railhook/php) | `composer require railhook/php` |

SDK для Node.js не має залежностей під час виконання. SDK для PHP потрібні `ext-json` і `ext-curl`.

## Надсилання події

<Tabs syncKey="lang">
  <TabItem label="Node.js">
    ```ts
    import { Railhook } from '@railhook/node';

    const client = new Railhook({
      apiKey: process.env.RAILHOOK_API_KEY,
      baseUrl: 'https://railhook.io', // or your instance
    });

    const event = await client.events.send(
      { type: 'order.completed', data: { orderId: 'ord_12345', amount: 99.99 } },
      'order-12345-completed', // idempotency key, optional
    );
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import os

    from railhook import Railhook, Event

    client = Railhook(
        api_key=os.environ["RAILHOOK_API_KEY"],
        base_url="https://railhook.io",  # or your instance
    )

    event = client.events.send(
        Event(type="order.completed", data={"order_id": "ord_12345", "amount": 99.99}),
        idempotency_key="order-12345-completed",
    )
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    <?php
    use Railhook\Railhook;

    $client = new Railhook(
        apiKey: getenv('RAILHOOK_API_KEY'),
        baseUrl: 'https://railhook.io', // or your instance
    );

    $event = $client->events->send(
        type: 'order.completed',
        data: ['orderId' => 'ord_12345', 'amount' => 99.99],
        idempotencyKey: 'order-12345-completed',
    );
    ```
  </TabItem>
</Tabs>

## Перевірка підпису

Передайте необроблене тіло запиту, заголовок `X-Signature` і секрет ендпоінта. Якщо підпис не збігається або мітка часу застаріла, перевірка викидає виняток.

<Tabs syncKey="lang">
  <TabItem label="Node.js">
    ```ts
    import { verifySignature } from '@railhook/node';

    verifySignature(rawBody, req.headers['x-signature'], process.env.WEBHOOK_SECRET);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    from railhook import verify_signature

    verify_signature(raw_body, headers.get("X-Signature", ""), os.environ["WEBHOOK_SECRET"])
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Railhook\Webhook;

    Webhook::verifySignature($payload, $headers['X-Signature'] ?? '', getenv('WEBHOOK_SECRET'));
    ```
  </TabItem>
</Tabs>

Кожен SDK також має `constructEvent` (`construct_event` у Python), який перевіряє й розбирає подію одним викликом. Якщо ваш ендпоінт використовує заголовки Standard Webhooks, викликайте `verifyStandardWebhook` (`verify_standard_webhook`) із секретом ендпоінта `whsec_`.

<Aside type="tip">
SDK не охоплюють трансформацій, правил, воркфлоу, схем, DLQ, сповіщень і адміністрування проєктів. Для цього в кожному SDK є універсальний метод для довільного запиту, а всі ендпоінти API перелічено в [довіднику API](/docs/uk/api-reference/).
</Aside>
