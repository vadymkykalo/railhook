# CLAUDE.md — railhook-docs

The public docs: Astro + Starlight, English at `/docs/<slug>/` and Ukrainian at
`/docs/uk/<slug>/`. Built into the UI image (`railhook-ui/Dockerfile`, `docs` stage) and served
by its nginx. `make docs-dev` runs it on http://localhost:4321/docs/; `make docs-check` is what
CI runs.

## The slug contract

`src/data/slugs.mjs` is the list of pages and the sidebar order, read by `astro.config.mjs`.
A new page is a slug added there plus both files:

- `src/content/docs/<slug>.mdx`
- `src/content/docs/uk/<slug>.mdx`

The sidebar shows a contract slug only once its English page exists, so an unwritten page
never breaks the build. `scripts/check-parity.mjs` (and its test) fails when one language has
a page the other lacks — Starlight would otherwise quietly show English with a "not translated"
notice. A Ukrainian page is a real translation with the same structure and the same code, not a
summary; code, env vars, paths and HTTP stay untranslated.

## Writing a page

```mdx
---
title: Retries & failed messages
description: One sentence, shown under the title and in search.
---
import { Steps, Tabs, TabItem, Aside, Card, CardGrid, LinkCard } from '@astrojs/starlight/components';
```

- Open with what the page lets the reader do. No preamble.
- Procedures: `<Steps>`. Alternatives: `<Tabs syncKey="lang">` (`Node.js`, `Python`, `PHP`,
  `cURL`) or `<Tabs syncKey="install">`. Warnings: `<Aside type="tip|caution|danger">`.
- Code fences carry a language, and a `title="…"` where it helps.
- Internal links are absolute, with the base and a trailing slash: `/docs/outgoing/retries/`,
  `/docs/uk/outgoing/retries/`. The build's links validator fails on anything else, and on a
  link to a page that does not exist.
- End with a "Next steps" `<CardGrid>` of two or three `<LinkCard>`s.
- Terms come from the root `CONTEXT.md`; respect its `_Avoid_` lines.

## Never hand-write a reference

- **Endpoints** — link to `/docs/api-reference/`. That page is Scalar over the root
  `openapi.yaml` (copied to `public/` by `scripts/copy-openapi.mjs`), which
  `OpenApiDriftIntegrationTest` holds to the running API. An endpoint table in a page is a copy
  that nothing keeps in sync.
- **Environment variables** — use the component, which renders every variable in `.env.dist`:

  ```mdx
  import EnvReference from '../../../components/EnvReference.astro';     {/* en page */}
  import EnvReference from '../../../../components/EnvReference.astro';  {/* uk/ page */}

  <EnvReference />
  ```

  Its data is `src/data/env-reference.json`, generated by `npm run env:reference` from
  `.env.dist` and committed; `env-reference.mjs --check` fails CI while it is stale. To change a
  description, change the comment in `.env.dist`.

## Facts

Every env var, flag, endpoint, default, port and limit on a page must be verified in the
repository — `.env.dist`, `application.yml`, `install.sh`, `openapi.yaml`, the controllers,
`docker-compose.yml`, the Helm `values.yaml`. If it cannot be verified, leave it out.

## Theme

`src/styles/theme.css` maps the Railhook tokens onto Starlight's variables for both themes.
Manrope is for the page title and site title only; body is Onest; code is JetBrains Mono on a
dark surface in both themes. Status hues (ok / retry / halt) are for statuses only — caution and
danger asides — never for chrome, and the accent never stands for a status.
